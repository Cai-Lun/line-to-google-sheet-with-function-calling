# Line 記帳機器人 (Google sheet)

### 功能簡介
在 Line 使用自然語言，透過 Gemini LLM 來解析出帳務資訊，存到指定的 Google sheet 裡。

### Demo
![](./public/demo.gif)

### 使用方式
Clone 此專案，或是 Fork 到你自己的 repo，將專案與 Vercel 做綁定，設定好需要的環境變數後，即可開始使用服務。
